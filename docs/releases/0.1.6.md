# Issue Bridge 0.1.6

Fix duplicate Octocats in rendered tasks. When Tasks wraps or clones existing decorated markup, Issue Bridge now reuses one icon, places it before the title and removes duplicates belonging to that task. Subtasks retain their own icons. Note text, issue links, IDs and scheduling metadata are unchanged.

Typecheck, official Obsidian lint, build and 56 tests pass. Regression cases cover nested wrappers, existing duplicates, subtasks, overlapping processors and asynchronous DOM changes. No new live desktop or mobile verification was performed.

Update with BRAT or copy `main.js`, `manifest.json` and `styles.css` into `<vault>/.obsidian/plugins/issue-bridge/`, then reload the plugin and reopen the affected note. Checksums and GitHub build-provenance attestations accompany the release artifacts.
