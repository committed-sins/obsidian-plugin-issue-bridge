Obsidian Plugin Review corrections:

- Searchable settings on Obsidian 1.13+, with native headings and working refresh after sign-in, disconnect, sync and acknowledgement. Older versions retain the settings page; minimum version stays 1.11.4.
- Remove regex lookbehind for older iOS engines, unnecessary escapes and control-character regexes.
- Use window timers and Obsidian DOM helpers, with icons owned by their editor document.
- Validate GitHub responses, YAML/JSON configuration and local state before use.
- Run the official Obsidian ESLint rules in CI with zero tolerated warnings.

Typecheck, lint, build and all 46 tests pass. The settings paths have synthetic host coverage; no new live desktop, popout or iOS validation was performed.

Update with BRAT, or copy `main.js`, `manifest.json` and `styles.css` into `<vault>/.obsidian/plugins/issue-bridge/`, then reload Issue Bridge. Settings and credentials are retained. Checksums and GitHub build-provenance attestations are provided for all release artifacts.
