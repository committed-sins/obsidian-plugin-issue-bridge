# Issue Bridge 0.1.3

- Choose the repository property in settings, for example `urls`. Accepts a single URL or a list; uses the first valid GitHub repository URL for issue sync and README previews.
- Show a small GitHub Octocat beside imported issue links in the editor, Reading view and Tasks results, without adding icon markup to the task text.
- Enable **Respect Obsidian Tasks** by default. Add stable IDs and the GitHub issue creation date (UTC), following the saved Tasks emoji/Dataview format and global filter. Preserve local scheduling, priorities, dependencies, tags and existing IDs across syncs.
- Generate and verify GitHub build-provenance attestations for all release artifacts. Keep the README concise.

Install with BRAT or copy `main.js`, `manifest.json` and `styles.css` to `<vault>/.obsidian/plugins/issue-bridge/`, then reload the plugin. Existing settings and the `github_repo` default are preserved. Change **Repository property** to `urls` to use an existing URL property. Files in the old mapped note remain until manually removed or replaced by a subsequent mapped sync.

Verify downloads with `SHA256SUMS` and `gh attestation verify main.js --repo committed-sins/obsidian-plugin-issue-bridge` (repeat for other files).

Typecheck, build and automated regression coverage pass. The additions have not been visually tested in Obsidian. Mobile, live expired-token renewal and private README access remain unverified. The default GitHub App remains limited to Committed Sins; no permissions were expanded.
