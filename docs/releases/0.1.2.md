First public release of Issue Bridge for Obsidian.

- Import your assigned GitHub issues as native Markdown tasks in existing notes with a `github_repo` property. GitHub supplies titles, links and open/closed states; surrounding note content remains intact.
- Check manually, every five minutes by default, and on startup/resume. New assignments appear in an Obsidian notice and a device-local unread list.
- Display collapsible, read-only repository Markdown with an `issue-bridge` code block containing `README.md` or another relative Markdown path.
- Sign in through GitHub App device authorization; credentials use Obsidian SecretStorage. Public README previews also work without sign-in.
- Fix issue-title escaping so punctuation and Unicode remain readable in Live Preview, and refresh the settings count after acknowledging new issues.

### Install

Download `main.js`, `manifest.json` and `styles.css` into `<vault>/.obsidian/plugins/issue-bridge/`, then enable **Issue Bridge** under Community plugins. SHA256 checksums are supplied in `SHA256SUMS`. You can also install this GitHub repository through BRAT. This release is not yet listed in the Obsidian community directory.

### Scope and validation

Requires Obsidian 1.11.4 or later. Desktop tested on Windows with Obsidian 1.15.1 in a separate Test vault: real device login, assigned issue import, close/reopen, unassign, native/queried Tasks, periodic/startup synchronization, persistence across plugin reload, unread acknowledgment and repository Markdown rendering. Automated type/build checks and 36 tests pass.

The built-in GitHub App currently permits installation only in **Committed Sins**. For another organization or personal repositories, configure your own GitHub App client ID with Device Flow and Issues: read-only. Install it on the required repositories before signing in. Private README previews additionally require Contents: read-only; this release does not broaden app permissions automatically.

Mobile, live refresh-token expiry/renewal and private README access have not been validated on real devices/accounts. Renewal, offline/partial-result handling, duplicate mappings and concurrent edits have synthetic automated coverage. This is an initial 0.1.x release; keep a backup when adopting a new note-writing plugin.
