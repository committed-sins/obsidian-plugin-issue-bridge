# Issue Bridge 0.1.7

Add optional source tags. Under **Source tags → GitHub issues tag**, enter a tag such as `#source/github` (with or without `#`). Leave empty to disable additions. GitHub Issues is currently the only source; settings are structured per source for future connectors.

The tag is appended during sync even when **Respect Obsidian Tasks** is off. Identical tags are not duplicated, ignoring case. Changing or clearing the setting preserves existing tags; it only affects future additions. Local planning and task IDs remain intact.

Typecheck, official Obsidian lint, build and 62 tests pass. Coverage includes default migration, validation, exact tag matching, case and Unicode, both Tasks formats, disabled integration and full sync. No new live desktop or mobile verification was performed.

Reload Issue Bridge after updating the three plugin files. Configure the tag, then sync to apply it to existing imports. Previously stored tags require manual removal if no longer wanted.
