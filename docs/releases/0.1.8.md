# Issue Bridge 0.1.8

Type `:octocat:` in a note to display the GitHub Octocat in Live Preview, Reading view and Tasks results. Imported issues use the same shortcode. Source mode and code examples show the literal text.

This release also includes two changes previously available as local builds. Rendered tasks avoid duplicate Octocats, and **Source tags → GitHub issues tag** lets you mark imports for Tasks queries.

Synchronization, managed note updates, task formatting, repository previews and the unread issues dialog now live in separate modules. Existing issue IDs, local task metadata and settings are preserved.

Validated on Windows in Obsidian 1.15.1. The shortcode rendered in headings, prose, manual tasks and Tasks queries. Code examples retained the literal shortcode. Startup sync migrated three existing issue lines, a subsequent manual sync reported zero changes, and the repository README preview loaded. Typecheck, lint, build and 59 automated tests passed.

Update with BRAT or copy `main.js`, `manifest.json` and `styles.css` into the Issue Bridge plugin directory, then reload the plugin. Synchronize to apply the shortcode to existing imports.
