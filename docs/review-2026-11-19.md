# Obsidian Plugin Review corrections

| Review point | Change and verification |
| --- | --- |
| Raw HTML headings | Settings rows use `setName(...).setHeading()`. No direct heading elements. |
| Missing declarative settings and deprecated refresh calls | Shared named definitions are searchable on 1.13+. `update()` refreshes the modern tab; `display()` exists only as the pre-1.13 host fallback. Minimum stays 1.11.4. Tests exercise control changes and both refresh paths. |
| Regex lookbehind | Marker scanning matches newline-inclusive lines without lookbehind. LF, CRLF, final lines without newline, fences and marker guards are covered. The built bundle contains no lookbehind. |
| Unqualified timers | Authorization waits use `window.setTimeout/clearTimeout`. Completion and cancellation are tested. |
| Unsafe values | Narrow GitHub array elements, frontmatter, Tasks JSON, settings and local state from `unknown`. Stored state validation retains valid credentials, snapshots and unread entries while rejecting malformed fields. |
| Control characters in regex | Check path character codes instead. Tests cover all ASCII control characters. |
| Unnecessary escapes | Simplify character classes and use a character string for Markdown title escaping. Existing title and Tasks tests pass. |
| Native `document.createElement` | Use Obsidian `createSpan`, adopting the disconnected icon into the editor's owning document. Visibility listeners retain their registered document. |

`npm run check` now includes the official `eslint-plugin-obsidianmd` recommended configuration with `--max-warnings 0`, including the reported unsafe-value and deprecation rules. Tests, build scripts and upstream reference sources are excluded from plugin linting. CI and release builds invoke the same check.

The linter's transitive `eslint-plugin-n` dependency pins `minimatch` to 11.0.1 to avoid GHSA-g3hv-75wg-m249. This is development tooling only; none of the ESLint packages are bundled into the plugin. The tooling requires Node 22.13+; CI uses Node 24.

Validation: typecheck, official lint rules, build and 46 tests pass. New automated cases cover settings definitions/fallback, stored-state validation, marker boundaries, control characters and timer cancellation. No new live Obsidian, settings-search, popout or iOS test was performed. Prior desktop evidence remains in validation-2026-11-14.md.

API references: [Obsidian settings documentation](https://github.com/obsidianmd/obsidian-developer-docs/blob/main/en/Plugins/User%20interface/Settings.md), [official ESLint plugin](https://github.com/obsidianmd/eslint-plugin).
